# ScanFlow 0.4.13 — сборка 32

Установите поверх ScanFlow через SideStore, без удаления приложения. Bundle ID ua.autosplit.scanner сохранён.

- Исправлен выбор верха для компактных блоков текста: соседние печатные строки оцениваются вместе, изолированные печати не получают решающий голос. Учитывается уверенность OCR без обязательных словарных совпадений. Для спорного результата выполняется повторная проверка увеличенного текстового блока.
- Уже сохранённые страницы без ручного поворота повторно анализируются при открытии или экспорте. Ручные повороты сохраняются.
- Добавлен регулируемый контраст текста и печатей 0–150% для одной страницы или всего скана. В цветных белом/чистом фильтрах по умолчанию 75%. Светлая бумага сохраняется, серые штрихи затемняются, цвет печатей усиливается. Оригиналы не перезаписываются, фильтры не накапливаются.
- Импульсная вспышка сохранена. Режим постоянной подсветки не добавлялся. Фактическое разрешение отображается после снимка; 48 Мп со вспышкой не обещаются.

Сборка и автоматические проверки выполняются в GitHub Actions. Реальное распознавание пользовательских документов необходимо проверить на iPhone: скриншот не содержит исходного снимка и результатов Vision.
