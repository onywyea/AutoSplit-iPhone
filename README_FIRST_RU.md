# ScanFlow 0.4.14 — сборка 33

Установите IPA через SideStore поверх текущего ScanFlow без удаления приложения. Bundle ID ua.autosplit.scanner сохранён.

- Папки показывают количество сканов. Цвета назначаются автоматически, изменить цвет можно в меню папки.
- Перенос получает неизменяемый список ID и исходных папок выбранных сканов. В окне назначения отображаются названия и количество. Выберите папку и нажмите «Перемістити · N». При изменении исходного списка или ошибке записи перенос отменяется с объяснением, без подстановки всех файлов. После успеха выделение сбрасывается. Изображения и страницы остаются на месте, меняется только принадлежность к папке.
- Для дочери или сына в редакторе названия появляется отдельное поле имени ребёнка. Старые суффиксы, включая ПКМУ168_дочка_Аліна, разбираются при открытии.
- Следующий скан предлагает ПІБ военнослужащего из предыдущего именованного пакета. Оно применяется только нажатием кнопки, суффикс и родственная связь от прошлого пакета не переносятся автоматически. Предложение сохраняется вместе с новым сканом.

Предыдущие исправления поворота, контраста, фокуса и импульсной вспышки сохранены. Автоматические проверки и сборка выполняются GitHub Actions; интерфейс необходимо проверить на iPhone после установки.
