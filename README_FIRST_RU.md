# ScanFlow 0.4.12, сборка 31

Обновление поверх установленного ScanFlow через SideStore. Bundle ID ua.autosplit.scanner сохранён. Не удаляйте приложение с сохранёнными сканами.

- Исправлена отмена поворота бокового текста при слабом словарном распознавании. Уже сохранённые страницы без ручного поворота повторно анализируются при открытии или экспорте.
- Камера сохраняет preset photo, необходимый для 24/48 Мп. В интерфейсе раздельно показаны запрошенное и фактическое разрешения. iOS может вернуть меньшее разрешение в зависимости от условий и доступных режимов; увеличение числа пикселей программно не используется.
- Папки: создание, переименование, перенос одного или выбранных сканов. Удаление папки сохраняет её сканы в «Без папки».
- Уровень камеры: наклон относительно горизонтального стола, зелёный до 2°. Это показание датчика телефона, не измерение плоскости наклонного документа.
- Имена Прізвище_ІП и редактируемые суффиксы ПКМУ168 / ПКМУ975 / родственные связи. Предпросмотр точного имени PDF.
- Возвращена прежняя объёмная оранжевая иконка сканера со стеклянными слоями.

Нативная сборка и проверки выполняются GitHub Actions. Проверка реальной камеры и Vision на iPhone требуется после установки.
