# ScanFlow 0.2 — сканер для iPhone

Новая версия исходного проекта AutoSplit: камера → страницы → ФИО → PDF.
Разделение комплектов перенесено в подготовку задания для ChatGPT.

## Статус поставки

Это исходники обновления. Синтаксис Swift проверен парсером, структура пакета, YAML и иконка проверены локально. Xcode в этой среде отсутствует. Обновлённая iOS-версия не скомпилирована и не проверена на iPhone. Предыдущая версия 0.1 была успешно собрана пользователем через GitHub Actions и установлена; это НЕ подтверждает работоспособность новой камеры 0.2.
В CI добавлены 17 проверок ФИО, безопасных имён и геометрии обрезки. Локально эти Swift-проверки не запускались, потому что нет компилятора Swift.

## Что изменено

- Новый главный экран со списком нескольких сканов, поиском и массовым выбором.
- Собственная камера AVFoundation. Ручная съёмка и автоматический снимок после стабилизации листа. После снимка смените лист; в случае пропуска доступна кнопка спуска.
- Нет программного ограничения количества страниц. Фотографии пишутся на диск по мере съёмки; PDF также записывается постранично. Свободное место и память iPhone остаются физическими ограничениями. При малом остатке места появляется ошибка.
- Модель определения документа Vision, резервное определение прямоугольников и исправление перспективы.
- Редактор с четырьмя подвижными углами, ручным поворотом и восстановлением оригинального вида.
- Автоповорот по OCR четырёх ориентаций. Когда оценки близки, выводится просьба проверить направление. Изначально горизонтальные документы не поворачиваются текстом набок ради портретной формы страницы.
- Три варианта обработки: оригинальный, чистый, чёрно-белый.
- Осторожная очистка узкой рамки по краю цветом, оценённым по бумаге. По умолчанию включена; можно выключить. Области распознанного текста защищаются. Нераспознанный мелкий текст/подпись на самом краю может пострадать — сравните с оригиналом.
- Поиск ФИО по полному имени, контексту и отдельным паспортным полям. При единственном явном кандидате предлагается название; при нескольких людях требуется выбор. Приведение падежей и безошибочное определение погибшего среди родственников не реализованы.
- Красивый значок листа в мятной рамке на тёмно-зелёном фоне. Иконка сгенерирована ImageGen и встроена в Assets.xcassets.
- Экспорт отдельных многостраничных PDF через стандартное меню «Поделиться».

## Передача задач в ChatGPT

Выберите сканы → «Підготувати для ChatGPT». Отметьте нужные задачи:
- разделить комплект по вашим правилам;
- назвать по погибшему и родству;
- извлечь банковские реквизиты;
- создать TXT с данными;
- проверить края и поворот.

Приложение создаёт PDF и TXT задания. Кнопка «Копіювати завдання» кладёт текст в буфер обмена. «Підготувати й поділитися файлами» открывает системное меню. Если ChatGPT доступен в меню, выберите его. Иначе сохраните файлы в «Файлы», откройте нужный чат, прикрепите PDF и вставьте текст задания. «Відкрити ChatGPT» открывает https://chatgpt.com; эта кнопка сама не прикрепляет файлы.

API и платных SDK нет. Автоматической отправки в существующий конкретный чат нет. Ограничения загрузки/размера файлов ChatGPT остаются независимо от отсутствия счётчика страниц в сканере. Текст задания можно менять перед отправкой.

## Обновление вашего существующего GitHub-репозитория с Windows

Удалять установленное приложение не нужно.

1. Распакуйте архив и откройте ScanFlow_iPhone.
2. В вашем репозитории onywyea/AutoSplit-iPhone (используйте уже открытый репозиторий) откройте Code → Add file → Upload files.
3. Перетащите содержимое папок AutoSplit, scripts, tests ВМЕСТЕ С САМИМИ этими тремя папками, а также файлы project.yml и README_RU.md в область загрузки. Не загружайте всю внешнюю папку ScanFlow_iPhone. Проверьте, что пути начинаются с AutoSplit/, scripts/, tests/.
4. Commit changes. Существующие файлы с теми же путями должны быть заменены.
5. Существующий .github/workflows/build.yml от версии 0.1 менять не требуется: правила и тесты оставлены совместимыми с его командами сборки. Новый вариант этого workflow также есть в архиве для нового репозитория.
6. Actions → Build iPhone app → Run workflow → main → Run workflow.
7. После зелёного результата скачайте артефакт AutoSplit-unsigned, извлеките AutoSplit-unsigned.ipa.
8. В SideStore установите новый IPA поверх текущего AutoSplit. Bundle ID сохранён ua.autosplit.scanner. Не удаляйте приложение перед обновлением.

Новое имя на экране — ScanFlow. Старые данные AutoSplit 0.1 сохраняются в прежнем каталоге, но автоматически в новый список сканов не мигрируют. Экспортируйте нужные старые сканы до обновления и импортируйте PDF в новую версию.

Если загрузка папок в браузере не работает, не переносите .swift-файлы в корень: пути нужны для сборки.

## Новая сборка на Mac

Установить Xcode и XcodeGen → xcodegen generate → открыть AutoSplit.xcodeproj.
Для физического устройства требуется signing/ваша Team. В CI собирается unsigned IPA, который затем подписывает SideStore.

## Контрольный прогон на телефоне

1. Новый скан, 3–5 страниц, среди них одна боком. В автоматическом режиме сменить лист после каждого кадра.
2. Убедиться, что кнопка «Готово» ждёт сохранения последнего снимка.
3. Сравнить границы с оригиналом; попробовать лист на белом и тёмном столе.
4. Подвинуть четыре угла; проверить, что текст и печати не обрезаны.
5. Отключить очистку рамки и сравнить; исходник должен оставаться доступен.
6. Проверить предложенное ФИО, выбрать одного человека при нескольких кандидатах.
7. Экспортировать PDF и открыть его в «Файлах»: порядок, поворот и число страниц должны совпасть.
8. Выбрать несколько сканов, скопировать задание и подготовить файлы для чата.

Абсолютно точные границы на любом фоне и стопроцентное OCR не гарантируются. Нельзя восстановить закрытый угол или не попавшую в кадр часть листа без выдумывания содержимого. Приложение не генерирует текст, подписи или печати вместо потерянных частей документа.
