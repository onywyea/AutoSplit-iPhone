# ScanFlow 0.3.4 · сборка 17

Полный накопительный проект. Bundle ID ua.autosplit.scanner и хранилище ScanFlow-v2 сохранены. Установка поверх существующего приложения.

## Новый белый цветной профиль

Вместо сочетания CIDocumentEnhancer и общей белой точки применяется PaperLighting из Rules.swift. Локальная оценка освещения строится на сетке 36×48 по нейтральным ровным участкам бумаги. Начальное поле задаётся профилями у четырёх границ; используются интегральные моменты для проверки текстуры, процентильные оценки и гармоническая интерполяция.

Если доноров менее 60% сетки, внутристраничные оценки отбрасываются: поле света восстанавливается по полям бумаги. Это предотвращает подстройку освещения под серые копии/портреты на контрольной странице 18. Изображение корректируется по каналам RGB; пиксели не генерируются. Анализ ограничен 900 пикселями по длинной стороне; результат применяется к полному сохранённому изображению. Значения RGB не уменьшаются до JPEG-кодирования; относительный локальный контраст при плавном поле сохраняется приблизительно, а не побитово.

Коррекция выполняется после перспективы и до очистки края. Без подтверждённых границ фото автоматически не выбеливается. Режимы «Оригінальний», «Чистий», «Чорно-білий» не заменены. Ревизия обработки 13 запускает однократный пересчёт старых страниц.

## Проверка

Python-модель проверялась на двух присланных исходных фото. Контрольная обрезка выполнена вручную, поэтому этот тест не оценивает автоматический детектор углов. Подготовлен отдельный PDF для визуального сравнения. На странице 14 большой перепад освещения значительно уменьшен; на странице 18 сохраняется серая фактура ксерокопии. Это ограниченная проверка двух кадров, не обещание качества на любом документе и не подтверждение идентичности Google Drive.

Добавлены Swift-тесты равномерного листа, широкой тени, плотной серой копии, синей отметки, сохранения альфа-канала и отсутствия затемнения. Синтаксис и пакет проверены локально, Swift-компиляция и тесты запускаются в GitHub Actions. Нативная камера и производительность на iPhone здесь не проверены.

Все предыдущие функции выбора объективов, выгрузки оригиналов, удаления страниц, экспорта без числового префикса включены. Инструкция: READ_ME_FIRST_RU.md.
