# ScanFlow 0.3.1 · сборка 14

Полный накопительный проект. Устанавливается поверх ScanFlow с прежним Bundle ID ua.autosplit.scanner. Исходники и данные приложения не удаляйте.

- Корзина в просмотре скана: удаление текущей страницы с подтверждением и переходом к соседней.
- После удаления последней страницы просмотр не теряет кнопку возврата к камере.
- После удаления сбрасывается подготовленный экспорт PDF.
- Меню «…» в просмотре: стиль всех страниц и автоповорот текущей страницы.
- Все предыдущие исправления 0.3.0 включены: компиляционные упрощения Rules/tests, отрисовка лупы Canvas, исправленный поиск границ и отключение автоочистки при ненайденных границах.
- Новый алгоритм цвета в этом обновлении не заявляется. «Білий кольоровий» остаётся системным CIDocumentEnhancer amount 4, выбранный стиль можно применить ко всем страницам из просмотра.
- GitHub Actions использует стандартный macos-15-intel.

Проверены структура пакета и синтаксический разбор Swift. Сборка Xcode, удаление во время реального перелистывания и нативная обработка изображения здесь не запускались. Они требуют проверки на iPhone/GitHub Actions.

Инструкция: READ_ME_FIRST_RU.md. Предыдущие отчёты в validation относятся к указанным в них версиям и не подтверждают нативную проверку 0.3.1.
