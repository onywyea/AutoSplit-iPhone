# ScanFlow 0.4.10 · сборка 29

Установите новый IPA поверх существующего ScanFlow. Не удаляйте приложение: в нём хранятся сканы. Bundle ID ua.autosplit.scanner сохранён.

Быстрая замена листа: сравнивается содержимое выровненного документа (96×128), а не только его контур и общий кадр 16×16. Требуются два подтверждения изменения; защита от повторного снимка сохранена. Сокращена пауза после фотографии. Отпечаток снятого листа фиксируется один раз.

Фокус серии: первая фокусировка выполняется по обнаруженному листу, затем фокус сохраняется для следующих страниц. Касание и «Перефокусувати» доступны. Камера выбирает до 24 Мп, если формат объектива поддерживает этот размер. Подсказка о расположении листа не блокирует съёмку.

Размытие, уже присутствующее в оригинале, не устраняется повышением резкости. Обновление меняет съёмку, но не восстанавливает утраченные детали старых фотографий. На реальном iPhone изменения требуют проверки; CI проверяет компиляцию и основные алгоритмы.

# ScanFlow 0.4.9 · build 28

Исправление остаточных пикселей и штрихов у внешнего края.

- Для подтверждённой автоматической обрезки фотографии включён внутренний запас 0,4% короткой стороны, максимум 8 пикселей. Ручные углы и страницы импортированного PDF этим запасом не обрезаются. При выключенной очистке края запас отключён.
- После освещения и резкости выполняется отдельный завершающий проход. Он продолжает ровный цвет бумаги в узкой внешней полосе, защищая компоненты с формой букв, затем убирает тонкие остатки без требования к их общей длине.
- Толщина наклонного или изогнутого штриха измеряется по участкам, а не по высоте всей ограничивающей рамки.
- Цвет фона заменяется всеми каналами RGB одновременно: сохранение максимального исходного красного канала могло оставлять бледный след дерева. Яркость при замене не снижается.
- Счётчик изменений учитывает финальную очистку, поэтому экспорт изменённой страницы PDF использует обработанный результат.
- Ревизия обработки края повышена до 16. Откройте существующий документ: страницы пересчитаются из сохранённых оригиналов. После завершения экспортируйте PDF снова; ранее сохранённый внешний PDF сам не изменяется.

Это накопительное обновление: фокус серии, галерея, резкость, цвета, удаление страниц, сжатие, ПІБ и прежние функции включены. GitHub Actions собирает ScanFlow-0.4.9.ipa. Устанавливайте через SideStore поверх приложения, без удаления. Bundle ID ua.autosplit.scanner и каталог ScanFlow-v2 прежние.

Проверки: локальная модель на двух предоставленных оригиналах с вручную заданными физическими углами; проверка синтаксиса; нативные регрессионные тесты и сборка выполняются в Actions. Локальная модель не запускает Vision/UIKit и не является проверкой на iPhone. Гарантировать отсутствие любых артефактов на произвольном изображении нельзя.
