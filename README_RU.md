# AutoSplit iPhone — исходный проект 0.1

Это первый исходный проект, а не проверенное установленное приложение.
В среде разработки этой поставки нет macOS, Xcode и iPhone, поэтому сборка и работа на устройстве ещё не проверены. Не использовать как готовую замену AutoSplit V3.0.

## Что реализовано в коде

- Системная камера сканирования с ручной корректировкой границ в интерфейсе камеры.
- Импорт PDF и изображений из «Файлов».
- Поиск прямоугольника документа и исправление перспективы. При неоднозначных границах — предупреждение. Оригиналы не перезаписываются.
- OCR четырёх ориентаций; при близких оценках поворот не применяется. Естественно горизонтальный документ остаётся горизонтальным, если текст уже читается правильно.
- Правила заголовков, перенесённые частично из AutoSplit V3.0: приоритет протокола ВЛК перед упоминанием свидетельства, приложение к протоколу не создаёт новый протокол, отдельные заголовки экспертных решений, паспорт с выпиской территориальной громады.
- Предварительные границы, ручное изменение границ, поворот, восстановление оригинала, удаление и перестановка страниц, просмотр всех страниц раздела.
- Сохранение одной текущей сессии между запусками.
- Экспорт отдельных PDF, TXT с реквизитами и примечаниями. IBAN проверяется по mod 97. Текст реквизитов сохраняется полностью, поля банка не структурируются.
- Экспорт требует явной отметки проверки каждого раздела.
- Работа локальная, в исходниках нет сетевой передачи документов и платных SDK.

## Что пока НЕ реализовано

- Надёжное автоматическое извлечение ФИО военнослужащего/родственников, родства и имён: эти поля пока вводятся вручную.
- Excel, глобальное согласование V3.0, редактор правил и обучение.
- Разделение паспорта и РНОКПП, расположенных на одном изображении.
- Надёжное отделение двух однотипных документов без повторного заголовка.
- Полное автоматическое заполнение банковских полей, проверка принадлежности реквизитов конкретному человеку.
- Точный набор пользовательских TXT-полей из старых скриншотов: вместо него поле примечаний.
- Архив нескольких комплектов, ZIP-экспорт, массовая обработка тысяч страниц.
- Удаление во время OCR: в этой версии нужно нажать «Зупинити» и дождаться окончания текущей страницы. Проверка отмены выполняется между страницами.
- Ручное перемещение углов для уже импортированного PDF; ручная обрезка доступна при съёмке системной камерой.

Системный OCR проверяет доступные языки во время работы. Если uk-UA не поддерживается на конкретной iOS, приложение показывает предупреждение. Отдельный украинский OCR пока не включён. Качество украинских документов не измерялось.

## Получение сборки, когда у вас Windows

В архиве есть workflow GitHub Actions для удалённого macOS-раннера. Это подготовленный путь сборки, ещё не запущенный на реальном аккаунте.

1. Создать репозиторий GitHub и загрузить туда СОДЕРЖИМОЕ этой папки: project.yml, AutoSplit/ и скрытую папку .github/. Сканов и персональных данных в репозитории быть не должно.
2. В Actions выбрать «Build iPhone app» → Run workflow.
3. Если сборка прошла, скачать артефакт AutoSplit-unsigned и извлечь IPA.
4. Этот IPA НЕ подписан и напрямую на iPhone не устанавливается. Нужна личная подпись совместимым инструментом установки с Windows (например, AltStore) и Apple ID. Условия, ограничения, срок подписи и доступность бесплатного раннера нужно проверить до использования. Не передавайте пароль Apple ID в чат или workflow.

Разработчик не запускал этот workflow и не подтверждает бесплатность/доступность для конкретного аккаунта. Репозиторий и внешние аккаунты в рамках этой поставки не создавались.

Если есть доступ к Mac: установить Xcode и XcodeGen, выполнить `xcodegen generate`, открыть AutoSplit.xcodeproj. Для установки через Xcode нужно включить signing, выбрать свою Team и уникальный bundle identifier; CODE_SIGNING_ALLOWED в project.yml сейчас выключен для unsigned CI.

## Первый запуск на iPhone

1. Снять небольшой комплект (5–10 страниц) или импортировать PDF.
2. Указать ФИО и основу имени, например Карпачов_РВ_ПКМУ168.
3. Нажать «Розпізнати та розділити»; обработка четырёх ориентаций может занять время.
4. Проверить границы в «Сторінки», затем названия и каждую страницу разделов.
5. Для реквизитов указать ФИО получателя и родство, исправить OCR-текст по изображению.
6. Отметить разделы как проверенные и экспортировать в «Файлы» или другое приложение.

Повторный анализ и перестроение границ заменяют ручную разметку разделов. Исходные изображения остаются. Новый комплект заменяет текущую сессию: сначала экспортируйте её. Старые изображения автоматически не очищаются, поэтому длительная работа будет занимать память устройства.

## Проверки этой поставки

- Добавлены 16 регрессионных проверок правил Swift: ВЛК/свидетельство, приложение к протоколу, продолжение витяга, паспорт/РНОКПП на общем листе, перечень приложений в заявлении, контрольная сумма IBAN и безопасные имена. Они запускаются в CI; локально Swift отсутствует и эти проверки не выполнялись.
- Включён scripts/check_package.py: проверяет состав проекта и регрессионные примеры правил по общей JSON-фикстуре через отдельный Swift runner в CI.
- Компиляция SwiftUI/VisionKit и испытание камеры возможны только после macOS-сборки/запуска на iPhone.
