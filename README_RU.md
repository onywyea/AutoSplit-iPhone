# ScanFlow 0.2.8 · сборка 10

Полный исходный проект; Bundle ID ua.autosplit.scanner и формат базы сохранены. Обновление устанавливается поверх приложения. ZIP содержит исходники, IPA собирается через ваш GitHub Actions.

## Исправления по скриншотам IMG_4916 / IMG_4917

1. Старый фильтр красных печатей принимал некоторые коричневые пиксели дерева за красные чернила. Защита уточнена по разнице каналов. Красные и синие чернила остаются защищены. В tests/main.swift добавлены реальные цвета оставшихся фрагментов стола.
2. Вокруг найденного внешнего фона добавлена сплошная зона замены. Она захватывает отделённые фрагменты и промежутки около контура, а затем переходит в плавное смешивание с бумагой. Чёрные контрастные штрихи и цветные отметки защищаются. Внутренние рамки документа по-прежнему не используются для автоматического обрезания PDF.
3. Первый ползунок теперь «Запас очищення за контуром»: 0–24 пикселя обрабатываемого изображения, по умолчанию 8. Он меняет саму область замены. Ранее этот ползунок менял область поиска и мог почти не влиять на уже обнаруженную тонкую кайму.
4. Второй ползунок регулирует плавный переход внутрь бумаги. Предпросмотр обновляется после короткой паузы при движении, расчёты объединяются и выполняются последовательно.
5. При открытии редактора заново вычисляется результат из оригинала. Показывается ход пересчёта, результат поиска фона и число пикселей основной маски замены; это не число изменённых пикселей финального изображения с учётом плавного перехода. При отключённой очистке есть явное пояснение.
6. При открытии существующего документа обработка края обновляется из его сохранённых оригиналов. Ручные углы, поворот и настройки сохраняются.
7. Включено исправление компиляции PDFExport.swift. Удаление выбранных сканов, украинское «ПІБ», сжатие PDF и просмотр страниц сохранены.

## Что проверено

В журнале предыдущей версии 0.2.7 все 85 тестов логики прошли. Для 0.2.8 добавлены проверки реальных коричневых цветов, защиты красного/синего/чёрного, удаления отделённого фрагмента, действия запаса очистки и сохранения центра листа.
Локально выполнены 17 проверок отдельной Python-модели маски, проверка структуры проекта и синтаксический разбор Swift-файлов. На показанном фрагменте исходного вида страницы осталось 8 тёплых пикселей вне новой маски вместо 741 вне старой; это диагностический результат на скриншоте, не оценка готового изображения на iPhone.
Здесь нет Swift/Xcode/iPhone. Нативная компиляция и новые Swift-тесты требуют запуска GitHub Actions; качество на камере, скорость и сохранность содержимого необходимо проверить на устройстве.

## Ограничения

Это исправление наружной каймы, не универсальная ретушь всего листа. Если бумага и фон почти одного цвета или вместо листа выбран весь кадр, потребуется уточнение углов. Автоматическая маска не гарантирует полного отсутствия ошибок. Проверяйте печати и подписи.
На присланных скриншотах вертикальная фактура слева видна даже при выключенной очистке. Для выяснения её источника нужен исходный снимок этой страницы без интерфейса. Бледные линии нельзя без проверки стирать как шум: это может быть содержание документа.
Не запускайте полное восстановление с оригиналов без необходимости: оно сбрасывает ручные настройки. Для этой версии достаточно открыть документ и дождаться обработки либо выбрать «Обробити краї всіх сторінок».
