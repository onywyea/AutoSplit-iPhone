# ScanFlow 0.4.1 · build 20

## Исправление сборки 0.4.1

По присланному журналу все 179 проверок ядра прошли на GitHub, затем Xcode 16.4 остановился на App.swift:31:24 с ошибкой таймаута проверки типов большого body SwiftUI. Это ошибка структуры интерфейса, не проблема сервера.

LibraryView разделён на отдельные границы типов: список, панели, toolbar, презентации и диалоги. LibraryComponents.swift содержит самостоятельные компоненты бренда, продолжения комплекта, пустого списка и строки документа. Итоговый экран и действия сохраняются.

Обязательно загрузите новый AutoSplit/LibraryComponents.swift вместе с остальными файлами. Архив полный: прежние обновления устанавливать отдельно не требуется. Запустите новый Run workflow после загрузки. Исправленная версия проверена парсером Swift и проверкой пакета, но нативная компиляция здесь недоступна; успешная сборка 0.4.1 пока не подтверждена.

Нативный SwiftUI проект. Основные инструкции: READ_ME_FIRST_RU.md.

Design.swift: адаптивный модификатор Liquid Glass с проверкой компилятора (Swift 6.2+) и iOS 26, regularMaterial fallback, непрозрачная поверхность при accessibilityReduceTransparency. Общая марка ScanMark и реальные статусы Leaf.reviewReason.

App.swift: компактная библиотека, поиск, возобновление последнего документа, прямая съёмка нового скана, импорт, выбор документов. DocumentWorkspace.swift: адаптивная lazy-сетка, фильтр предупреждений, выбор страниц, пакетный стиль/удаление/отмена, порядок страниц. PageBrowser.swift: существующий UIPageViewController и кэш соседей сохранены; отдельная панель инструментов под документом, ручная отметка проверки, следующий проблемный лист, экспорт и отмена удаления.

DocumentStyleSheet получает необязательное pageIDs. Store.applyStyle обрабатывает только целевые страницы; preferredFinish меняется только для всего документа. Массовое удаление сохраняет позиции и Leaf для отмены в текущей сессии экрана; восстановление не заменяет уже существующие UUID. Никакие дисковые файлы этой операцией не удаляются. Все изменения сбрасывают подготовленные ссылки экспорта. Ручная отметка reviewed опциональна для совместимости со старым JSON.

PageEditor переиспользует уже рассчитанный актуальный preview для сохранения, не запускает второй полный рендер при автосохранении. Начальная загрузка не помечает страницу изменённой. Версия расчёта предотвращает подтверждение сохранения устаревшего preview. Ошибки сохранения не считаются успешным автосохранением.

Статус «Перевірити» включает неподтверждённые физические границы, предупреждения о направлении/неуверенном OCR и ожидание распознавания. Это не классификатор резкости. Неподтверждённые границы камеры не обходятся ручной галочкой. После изменения изображения reviewed сбрасывается.

Capture/Focusing/PaperLighting/PDFCompression сохраняют логику 0.3.5; лимит новых originals 4096 px, JPEG 0.97, экспорт максимального качества по умолчанию. Имена PDF без цифрового префикса. Выгрузка исходников, переключение объективов, Live Text и удаление документов сохранены. База ScanFlow-v2, bundle ua.autosplit.scanner.

Нативная компиляция, регрессионные Swift-тесты и визуальная/производительная проверка iOS здесь не выполнялись. Parser/package/YAML checks — не замена Xcode build и тесту на iPhone. UI адаптирован для Dynamic Type через системные шрифты и adaptive grid; iPhone и iPad нужно проверить после сборки.
