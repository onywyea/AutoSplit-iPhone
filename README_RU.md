# ScanFlow 0.2.7 · сборка 9

Это исходники нативного приложения для iPhone, а не готовый IPA.
Bundle ID `ua.autosplit.scanner` сохранён. Устанавливайте обновление поверх существующего приложения через тот же SideStore: удаление приложения может удалить его локальные сканы.

## Что изменено

- Библиотека: компактные строки с миниатюрой, названием, датой на украинском; системный поиск. «Вибрати» → отметить документы → «Видалити» с подтверждением. Есть «Усі». После сохранения списка удаляются файлы выбранных сканов, если они не используются другими документами. Сохранённые вне приложения PDF не затрагиваются.
- Экспорт выбранных документов: нижняя кнопка «Експорт». Внутри документа экспорт доступен в верхней панели. Там три режима: максимальное качество, сбалансированный и маленький файл. После подготовки виден настоящий общий размер PDF и кнопка сохранения/отправки. ChatGPT находится среди дополнительных действий.
- Во всём интерфейсе используется «ПІБ».
- Обработка края теперь учитывает нейтральный серый фон наряду с тёплым. Внешняя область заполняется до найденного контура, включая светлые разрывы в фактуре стола. Переход продолжается внутрь бумаги: первая треть перехода непрозрачная, затем плавное смешивание. Убрана синтетическая зернистость.
- Ширина поиска внешнего фона и ширина перехода внутрь бумаги регулируются отдельно: «Редагувати» → «Налаштування краю». По умолчанию 8% и 6%. Пользовательские настройки прежних сканов сохраняются. Новая обработка существующих страниц запускается при открытии документа из сохранённых оригиналов.
- Из редакторов углов и кисти убрано чтение полного изображения при каждом движении пальца. Загрузка выполняется асинхронно с кэшем. Пересчёты предпросмотра выполняются по очереди, повторные изменения объединяются. Отрисовка импортированных PDF также вынесена из основного потока.
- Сохранены исправления сборки 0.2.6: явный self в замыканиях просмотрщика и исправленная обработка ошибки в Store.

## Сжатие

«Збалансовано» выбрано по умолчанию: длинная сторона до 2200 px, JPEG 0.78.
«Малий файл»: до 1500 px, JPEG 0.60; мелкий текст может потерять чёткость.
«Максимальна якість»: фотографии без дополнительного перекодирования. Для неизменённых импортированных PDF сохраняются исходные страницы и текстовый слой.

Сжатые PDF состоят из изображений страниц, текстовый слой исходного PDF при таком экспорте не переносится. Сжатие создаёт отдельный файл и не меняет оригинал. Размер зависит от содержания: обещания конкретного процента уменьшения нет. Например, векторный PDF может быть меньше растровой сжатой копии — для него лучше максимальное качество.
Страницы записываются по одной, без удержания всего PDF в памяти.

## Что остаётся ограничением

Очистка края не восстанавливает достоверно отсутствующий текст и не является генеративной ретушью. Она работает в наружной зоне правильно обрезанного листа. Если вместо документа выбран весь кадр с полом, нужно уточнить четыре угла или переснять. Фон близкого к бумаге цвета и сложные тени могут не определиться. Синие и красные отметки и контрастный текст в переходе защищаются, но автоматическое выделение не может гарантировать отсутствие ошибок. Проверяйте результат рядом с печатями и подписями.

## Проверки

Локально проверены структура пакета, совместимый Bundle ID, каталог иконки и синтаксическое дерево всех Swift-файлов. Отдельная Python-модель прошла 9 проверок маски: бумага без фона, дерево, серый фон, нетронутый центр, тонкая серая линия, синяя отметка, красная отметка, внутренняя рамка, светлый разрыв во внешнем фоне. На двух прошлых скриншотах обнаружена наружная кайма без изменения центра.
В tests/main.swift добавлены соответствующие проверки края и параметров экспорта. Они запускаются в GitHub Actions вместе с прежними тестами.

В этой среде нет Swift/Xcode и iPhone. Нативная компиляция, фактическое качество PDF-сжатия, жесты, плавность и обработка реальной камеры здесь не проверены. Синтаксическая проверка не заменяет сборку и запуск на устройстве.
