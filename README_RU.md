# ScanFlow 0.3.3 · сборка 16

Полный накопительный проект с прежним Bundle ID ua.autosplit.scanner. Все исправления 0.3.2 включены.

- Выбор реального заднего объектива через AVCaptureDevice.DiscoverySession: основная камера, ультраширокоугольная, телеобъектив при наличии.
- Смена AVCaptureDeviceInput в beginConfiguration/commitConfiguration, восстановление старого входа при canAddInput == false. Сохранение успешного выбора в UserDefaults.
- Повторная настройка фокуса, экспозиции, размеров фото и ориентации подключения; пауза детектора и сброс накопленной устойчивости после переключения.
- Проверка поддержки вспышки для выбранной физической камеры. Мощность фотоимпульса вручную не регулируется.
- Меню экспорта одного или всех сохранённых оригиналов. Копирование существующих файлов без отрисовки и перекодирования. Исходники остаются на месте; старый подготовленный PDF этим действием не подменяется.
- Новый OriginalsExport.swift должен находиться внутри AutoSplit.

Синтаксический разбор и проверка пакета выполнены. Компиляция Xcode, работа физических камер, фокусировка, вспышка и ShareSheet не проверены на устройстве. Нативные тесты ядра выполняются GitHub Actions. Новый алгоритм удаления теней в этой версии не заявляется.
