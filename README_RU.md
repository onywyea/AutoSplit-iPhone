# ScanFlow 0.4.4 · build 23

## Исправление компиляции 0.4.4

В присланном журнале logs_112762062609.zip подтверждён iOS SDK 26.5. Проверка ядра остановилась на Rules.swift:867: составная формула расчёта яркости вызвала таймаут проверки типов Swift. Формула и соседние расчёты разделены на простые операции с явными Int/Double. Значения коэффициентов, округление, усиление штрихов, цвета и новая иконка не изменены.

Это полный проект. После загрузки запустите новый Run workflow. Нативная компиляция исправления локально недоступна; успешная сборка пока не подтверждена. Синтаксис, пакет и эквивалентность целочисленных вычислений проверены.

Инструкции: READ_ME_FIRST_RU.md. Полный исходный проект, не IPA.

Theme.swift: динамическая графитовая/тёплая палитра, контрастный коралловый accent, ScanCard, кнопки glassProminent/glass и непрозрачный ScanPillStyle для Reduce Transparency / старой iOS. ScanControls объединяет соседние стеклянные кнопки в GlassEffectContainer. AppearanceSheet хранит тему через AppStorage и показывает активную ветку эффектов. При компиляторе старее Swift 6.2 #error направляет к обновлению workflow; это намеренное исключение старого SDK.

App.swift: ScrollView + LazyVStack вместо List с insetGrouped. Разделение компонентов 0.4.1 сохранено для уменьшения нагрузки на type checker. LibraryComponents.swift: карточки бренда/возобновления/документа; статусы читаются из реальных данных. DocumentWorkspace.swift: новые фильтры и кнопки; PageBrowser.swift и CropEditor.swift: инструменты в отдельных капсулах, подписи остаются видимыми. ScanBackdrop — статическая цветная подложка, без постоянной анимации. Design.swift: общая отметка/статусы и прежний модификатор стеклянных управляющих панелей. Скан не покрывается декоративными эффектами.

Workflow требует стабильный Xcode 26 на macos-26-intel и проверяет SDK >=26. Отсутствие SDK больше не превращается в успешную сборку старого оформления. На iOS 17–18/другой iOS младше 26 используются совместимые непрозрачные/материальные элементы; системное Reduce Transparency выключает прозрачность. iOS deployment target остаётся 17.0.

В 0.4.3 Rules.swift добавляет DocumentDetail и CaptureSampling; Pipeline.finish применяет ограниченное тёмностороннее усиление деталей к белому/чистому профилю. Store переносит соответствующие старые страницы на ревизию 14. Camera учитывает достаточный размер листа, TextDetail использует порог 0,48. Нативная проверка обязательна. Models/PDFExport/JSON совместимы с прежним хранилищем. 179 проверок ядра ранее прошли в присланном GitHub-логе. Нативная сборка этой версии локально недоступна и не заявляется успешной.
