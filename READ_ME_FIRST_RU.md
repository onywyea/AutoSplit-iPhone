# ScanFlow 0.3.3 · сборка 16

Полный исходный проект для GitHub Actions. Это НЕ установочный IPA.

1. Распакуйте ZIP и откройте ScanFlow_Update.
2. Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория AutoSplit-iPhone с заменой файлов: AutoSplit, scripts, tests, project.yml. В папке AutoSplit теперь также должен быть OriginalsExport.swift.
3. Сохраните Commit changes. В .github/workflows/build.yml оставьте runs-on: macos-15-intel.
4. Actions → Build iPhone app → Run workflow → main. После успешной сборки скачайте AutoSplit-unsigned, извлеките IPA и установите через SideStore поверх ScanFlow. Приложение не удаляйте.

## Выбор объектива

Откройте камеру. Под верхним рядом кнопок находится меню с названием объектива: «Основна», «Ультраширококутна», «Телеоб’єктив». Показываются только физические задние камеры, найденные на устройстве. Это не цифровое увеличение. Последний успешный выбор сохраняется.

На время снимка, обработки или переключения выбор блокируется. После смены объектива контур и таймер автоснимка сбрасываются, камере даётся время на настройку. При отказе добавления нового входа восстанавливается предыдущий. Доступность вспышки проверяется для выбранной камеры; если она недоступна, интерфейс показывает «Без спалаху».

Проверьте на устройстве каждый объектив: изображение в видоискателе, фокусировку, ручной снимок, автоснимок, ориентацию сохранённого фото, вспышку и запоминание после повторного открытия.

## Сохранённые оригиналы

Откройте нужную страницу → «…» → «Поділитися оригіналом» → «Зберегти або поділитися оригіналами» → «Сохранить в Файлы». Переключатель «Усі сторінки документа» выгружает весь комплект.

Можно также открыть меню «…» документа → «Експорт оригіналів фото». Имена файлов содержат фактический номер страницы, например Сторінка_14_оригінал.jpg. Файлы копируются до фильтров, без нового JPEG-кодирования; при первоначальном сохранении ScanFlow уже мог уменьшить фото до 3000 пикселей и записать его в JPEG. Это сохранённые исходники приложения, не RAW и не обязательно оригинальный файл камеры полного разрешения.

Если приложение сообщает, что оригинал отсутствует, оно не подменяет его обработанным изображением. PDF и данные скана при выгрузке не меняются.

Для проверки теней нужны оригиналы страниц 14 и 18 последнего комплекта. Их можно приложить в чат после сохранения.

Обработка изображения в 0.3.3 не менялась. Нативная сборка, переключение камер и системное меню обмена здесь не запускались: требуется GitHub Actions и проверка на iPhone. Проверены комплектность и синтаксис Swift.
