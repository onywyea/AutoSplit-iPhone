# Установка обновления ScanFlow 0.2.7

1. Распакуйте ZIP. Откройте папку ScanFlow_Update.
2. На GitHub откройте репозиторий onywyea/AutoSplit-iPhone (ваш существующий AutoSplit-iPhone), вкладка Code → Add file → Upload files.
3. Перетащите СОДЕРЖИМОЕ папки ScanFlow_Update в корень репозитория: папки AutoSplit, scripts, tests и файлы project.yml, README_RU.md. Папка AutoSplit должна остаться прямо в корне. Подтвердите Commit changes.
4. Файл AutoSplit/PDFExport.swift обязательно должен появиться рядом с App.swift и Store.swift. В project.yml должна быть версия 0.2.7 и CURRENT_PROJECT_VERSION: 9.
5. Существующий .github/workflows/build.yml оставьте на месте. В архиве он также есть, но браузер может пропустить скрытую папку. Если процесс сборки уже работал, изменять его не нужно.
6. Actions → Build iPhone app → Run workflow → main. Дождитесь зелёного результата именно для нового коммита.
7. Откройте новый запуск, скачайте артефакт AutoSplit-unsigned, распакуйте его. Установите находящийся внутри AutoSplit-unsigned.ipa через «+» SideStore поверх текущего приложения.

Не устанавливайте старый IPA из прежнего скачивания. Приложение удалять не нужно.

После обновления:
- «Вибрати» → отметить сканы → «Видалити».
- «Експорт» → «Експорт / стиснення PDF» → выбрать качество → «Створити PDF» → проверить размер → «Зберегти або поділитися».
- Внутри документа открыть его экспорт значком отправки сверху.
- Старый документ открыть и дождаться обновления краёв; при необходимости меню «Обробити краї всіх сторінок». Не запускайте полное восстановление без необходимости: оно сбрасывает ручные правки.
- Для сложного края: «Редагувати» → «Налаштування краю» → отдельно настроить внешний фон и переход внутрь.

Проверка на iPhone: сначала один новый скан со штампом у края; сравнить с оригиналом, проверить углы, перелистывание и размер экспорта. Нативная проверка на устройстве необходима: здесь нет Xcode и iPhone.
