# Обновление ScanFlow 0.2.10

1. Распакуйте ZIP и откройте ScanFlow_Update.
2. GitHub → ваш AutoSplit-iPhone → Code → Add file → Upload files.
3. Перетащите СОДЕРЖИМОЕ ScanFlow_Update в корень репозитория: AutoSplit, scripts, tests, project.yml, README_RU.md. Не создавайте лишнюю папку ScanFlow_Update в репозитории.
4. Commit changes. Проверьте project.yml: MARKETING_VERSION 0.2.10 и CURRENT_PROJECT_VERSION 12. PDFExport.swift уже содержит исправление сборки.
5. Существующий .github/workflows/build.yml оставьте на месте.
6. Actions → Build iPhone app → Run workflow → main. Нужен новый запуск для нового коммита.
7. После зелёной сборки скачайте новый артефакт AutoSplit-unsigned, извлеките IPA и установите через SideStore поверх текущего приложения. Приложение не удаляйте.

Сначала проверьте страницы 2 и 11 исходного комплекта. Дождитесь автоматического обновления краёв. Включите очистку. Для сравнения с контрольным PDF установите 19 px и 12%. Сравните оба портрета, подпись, печати и нижний край. Старые ручные углы и следы кисти сохраняются и могут влиять на результат.

Контрольный PDF предоставляется отдельно: результат модели на двух реальных страницах. Нативную сборку здесь запустить невозможно — её проверяет GitHub Actions.

В этой версии устранены слабые красно-коричневые точки у внешней границы. При открытии документа дождитесь пересчёта из сохранённых оригиналов. Старые обработанные PDF лучше не импортировать как оригинал: для сравнения используйте исходный файл до обработки.
