# ScanFlow 0.3.0 · сборка 13

Это полный исходный проект для GitHub Actions, НЕ установочный IPA.

1. Распакуйте ZIP. Откройте папку ScanFlow_Update.
2. В GitHub откройте AutoSplit-iPhone → Code → Add file → Upload files.
3. Загрузите СОДЕРЖИМОЕ ScanFlow_Update в корень репозитория с заменой файлов. В корне должны быть папка AutoSplit, scripts, tests и project.yml. Swift-файлы из AutoSplit не переносите в корень.
4. Существующий .github/workflows/build.yml оставьте. Нажмите Commit changes.
5. Проверьте project.yml: MARKETING_VERSION 0.3.0, CURRENT_PROJECT_VERSION 13.
6. Actions → Build iPhone app → Run workflow → main. Дождитесь результата нового запуска.
7. После успешной сборки скачайте артефакт AutoSplit-unsigned, распакуйте его и установите AutoSplit-unsigned.ipa через SideStore ПОВЕРХ текущего ScanFlow. Приложение не удаляйте.

## Где новые функции

• При открытой камере приложение удерживает экран включённым. При выходе, сворачивании или переходе в просмотр обычная автоблокировка восстанавливается.
• Автоснимок переносит небольшую дрожь, изменение экспозиции и кратковременную потерю контура. Повторный снимок того же листа автоматически блокируется до смены сцены/листа.
• В редакторе углов при перетягивании появляется лупа с перекрестием, смещённая от пальца.
• Новый снимок и импортированное фото по умолчанию получают стиль «Білий кольоровий». PDF по умолчанию сохраняет исходный стиль.
• Откройте документ → «Стиль усіх сторінок» → выберите стиль → «Застосувати до всіх сторінок». Это также задаёт стиль следующих страниц этого документа.
• Вспышка по умолчанию включена; индикатор под затвором показывает, сработала ли она при последнем снимке. Мощность фотоимпульса выбирает iPhone; настройка экспозиции не является регулятором мощности вспышки.

## Проверка после установки

Оставьте открытую камеру дольше времени вашей автоблокировки. Затем снимите несколько страниц с небольшой дрожью рук: проверьте углы и отсутствие повторного снимка одного листа. В ручных углах проверьте лупу у всех четырёх углов. Примените белый цветной стиль ко всему комплекту и проверьте тени, печати, фото и мелкий текст; сравните со стилем «Оригінальний».

В этой среде проверены структура пакета и синтаксис Swift. Xcode/iPhone недоступны: сборку, нативные тесты и работу камеры проверяют GitHub Actions и устройство. Скорость и качество на вашем телефоне здесь не измерялись. Абсолютно белый результат при любом освещении не гарантируется; исходники страниц сохраняются для возврата и повторной обработки.
