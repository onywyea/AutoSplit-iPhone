# ScanFlow 0.2.8 · порядок обновления

1. Распакуйте архив. Внутри находится папка ScanFlow_Update.
2. Откройте существующий репозиторий onywyea/AutoSplit-iPhone → Code → Add file → Upload files.
3. Загрузите СОДЕРЖИМОЕ ScanFlow_Update в корень репозитория: папки AutoSplit, scripts, tests, файлы project.yml и README_RU.md. Не загружайте папку ScanFlow_Update как лишний уровень.
4. Нажмите Commit changes. Проверьте project.yml: MARKETING_VERSION 0.2.8, CURRENT_PROJECT_VERSION 10. Файл PDFExport.swift должен лежать в AutoSplit; он уже исправлен, вручную его редактировать не нужно.
5. Существующий .github/workflows/build.yml оставьте на месте. В архиве он также есть.
6. Actions → Build iPhone app → Run workflow → main. Нужен новый запуск для последнего коммита.
7. После успешной сборки скачайте новый артефакт AutoSplit-unsigned, извлеките IPA, установите через SideStore поверх приложения. Не удаляйте приложение.

Проверка после установки:
- Откройте документ и дождитесь обновления обработки.
- В редакторе включите «Автоматично очищати край».
- В «Налаштування краю» первый ползунок теперь показывает px. Начните с 8–12 px, сравните 0 и 24 px; дождитесь окончания пересчёта.
- Если указано «Фон не знайдено», увеличение запаса само по себе очистку не запустит: уточните углы.
- Сравните с оригиналом и проверьте печати/подписи перед сохранением.

Для диагностики вертикальной грязной фактуры нужен исходный снимок страницы без интерфейса приложения. Скриншот не позволяет установить её источник достоверно.
