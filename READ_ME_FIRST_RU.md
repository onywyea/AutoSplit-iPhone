# ScanFlow 0.4.0 · сборка 19

Полное накопительное обновление: новый интерфейс «Поток + Студия + Пакет». Включает изменения 0.3.5 по фокусу и разрешению. Это исходный проект для GitHub Actions, не готовый IPA.

## Установка

1. Распакуйте ZIP. Загрузите СОДЕРЖИМОЕ ScanFlow_Update в корень onywyea/AutoSplit-iPhone, заменив существующие файлы. Папка AutoSplit должна лежать прямо в корне репозитория. Новые файлы Design.swift и DocumentWorkspace.swift обязательны.
2. Actions → Build iPhone app → Run workflow → main. Нужен новый запуск после загрузки, не повтор старого коммита.
3. Скачайте артефакт AutoSplit-unsigned, извлеките IPA и установите поверх ScanFlow через SideStore. Bundle ID ua.autosplit.scanner и хранилище ScanFlow-v2 сохранены. Не удаляйте приложение перед обновлением.

## Главный экран — Поток

Компактная библиотека, поиск по названию/ПІБ, продолжение последнего открытого комплекта. «Новий скан» сразу открывает камеру. Импорт PDF/фото доступен рядом с этой кнопкой. Контекстное меню и выбор нескольких документов для экспорта/удаления сохранены.

## Комплект — Пакет

Адаптивная сетка страниц, фильтры «Усі / Перевірити / Готові», переход к проблемным страницам. «Вибрати» → несколько миниатюр → «Стиль» или «Видалити». В меню остаются общий стиль, порядок страниц, OCR, ChatGPT и выгрузка оригиналов. Применение стиля к выбранным страницам не меняет стиль остальных и будущих страниц. Стиль всего документа задаёт стиль будущих кадров.

После удаления страниц видна отмена последнего удаления; она доступна в текущем открытом экране. Файлы удалённых страниц не уничтожаются этой операцией. После закрытия экрана кнопка отмены не сохраняется.

## Просмотр — Студия

Перелистывание и миниатюры сохранены. Снизу — обрезка, ручной поворот, вид страницы и экспорт. Кнопка с галочкой подтверждает вашу визуальную проверку и переходит к следующей странице, требующей внимания. Если у фото не подтверждены границы, сначала задайте углы.

«Готові» означает отсутствие известных предупреждений/ожидания OCR либо вашу ручную отметку; это не оценка точности текста и не гарантия качества скана. После изменения изображения отметка проверки снимается. Настройки редактора автоматически сохраняются после завершения актуального расчёта; незавершённые изменения не позволяют случайно закрыть лист свайпом. Кнопка «Готово» сохраняет при необходимости и закрывает.

## Liquid Glass

Нативный glassEffect применяется к нижним панелям действий и верхней панели камеры при сборке Xcode 26+ и запуске iOS 26+. Полотно документа остаётся непрозрачным. Для iOS 17–18 / старого SDK используется regularMaterial. При «Понижение прозрачности» используется непрозрачная панель. Камера сохраняет тёмное оформление для читаемых индикаторов.

Workflow выбирает установленный Xcode 26+, если он есть. При отсутствии пишет предупреждение и собирает вариант с обычным материалом. Никаких платных библиотек или сетевой обработки документов нет.

## Проверка и ограничения

Проверены комплектность, синтаксис Swift и структура workflow. Нативный Swift-компилятор, Xcode, iOS, внешность Liquid Glass и скорость на реальном iPhone здесь недоступны. Это не проверенная нативная сборка. Алгоритмы камеры/фокуса/очистки 0.3.5 не менялись; улучшение качества съёмки в этом дизайнерском выпуске не заявляется. Новая объёмная марка используется внутри библиотеки; установленная иконка приложения сохранена.
