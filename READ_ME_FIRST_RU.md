# ScanFlow 0.4.8 · build 27

Полный проект для GitHub Actions. Это исходники, не готовый IPA. Предыдущее обновление устанавливать отдельно не требуется.

## Фокус для серийной работы

Режим «Фокус серії» включён по умолчанию и запоминается. При открытии камеры или смене объектива камера фокусируется один раз, затем сохраняет аппаратную блокировку между снимками. Прежнее принудительное включение непрерывного автофокуса после каждого снимка в этом режиме убрано. Экспозиция продолжает подстраиваться.

Зелёная надпись «Фокус серії зафіксовано» появляется по аппаратному режиму locked и отсутствию движения фокуса. Это признак фиксации объектива, а не гарантия читаемости текста.

Если меняется высота телефона над листом, нажмите «Перефокусувати» или коснитесь текста на документе. Камера снова выполнит один проход фокусировки и зафиксирует положение. Само появление следующей страницы не запускает новый проход. Для съёмки с постоянно меняющимся расстоянием нажмите «Фокус серії», чтобы переключиться в обычный непрерывный автофокус.

Стабильность контура документа и защита от повторного снимка одной страницы остаются: фиксация фокуса не заставляет снимать движущийся лист. Размер текста не блокирует автосъёмку; ручная кнопка доступна без подтверждения качества.

Нативная камера здесь не запускалась. Проверена структура изменения и синтаксис; фактическая скорость и поведение конкретного объектива требуют проверки на iPhone.

Архив включает все изменения 0.4.6: галерею, настройки края для всего документа, резкость, цвета и улучшения ПІБ. Предыдущий архив отдельно устанавливать не нужно.

## Что изменилось

- Отдельный поиск длинных тонких разорванных серых/синих полос у внешнего края страницы. Старый нахлёст зависел от найденной маски фона и не находил такие полосы сам. Поиск узкий: увеличение запаса расширяет его глубину; это не гарантирует удаление любого артефакта.
- Фон определяется по исходным цветам до выравнивания освещения. Внутренние границы таблиц не используются как новые углы импортированного PDF.
- В редакторе явно написано «Ця сторінка». Кнопка «Застосувати вигляд і край до всього скану» переносит стиль, резкость и оба параметра края на весь документ и новые фотографии. Она доступна после завершения автосохранения предпросмотра.
- «… → Стиль усіх сторінок» также позволяет настроить весь документ. Для выбранных в сетке страниц настройки применяются только к ним. Кадрирование, поворот и мазки кисти каждой страницы не копируются на другие страницы.
- Ползунок резкости 0–150%. В стилях «Білий кольоровий» и «Чистий» значение по умолчанию 85%; у оригинального и монохромного вида по умолчанию 0%. Можно изменить вручную в любом стиле. Пересчёт всегда из сохранённого оригинала, без накопления резкости.
- Внутри документа «Додати → Фото з галереї»: выбор нескольких фото в указанном порядке, добавление к текущему скану. Фото из iCloud может требовать интернет. Камера и импорт из «Файлов» остаются в том же меню.
- Оформление: пять акцентов (коралловый, синий, фиолетовый, зелёный, розовый), меньшие кнопки. Зелёные статусы готовности и красные кнопки удаления сохраняют свой смысл.
- Изменение только внешнего вида больше не удаляет распознанный текст. Распознавание объединяет фрагменты одной строки; поля имени свидетельства могут находиться в разных строках или одной строке. Первая страница имеет приоритет для автоматического названия, если в ней найдено одно явное ПІБ. При неудаче на ней выполняется дополнительный OCR исходного изображения без фильтра. Ручное название не заменяется автоматически.
- В «Назва» есть кнопка «Заново розпізнати ПІБ». Несколько разных людей остаются вариантами выбора, а не случайным названием.

## Как применить к существующему скану

Откройте документ. После обновления один раз выполняется пересчёт старых краёв из сохранённых оригиналов. Для единого вида откройте «… → Стиль усіх сторінок», выберите «Білий кольоровий», настройте резкость и край, нажмите «Застосувати». Это добровольная операция, не проверка каждой страницы.

При ненайденных границах фотографии сохраняются полным кадром; автоматическое удаление окружения в таком случае ограничено. При необходимости уточните углы. Проверять и подтверждать каждую страницу перед PDF не требуется.

## Установка через GitHub и SideStore

1. Распакуйте ZIP целиком. Внутри папки ScanFlow_Update находятся AutoSplit, scripts, tests, project.yml и .github/workflows/build.yml.
2. Загрузите содержимое этой папки в корень репозитория `onywyea/AutoSplit-iPhone`. Включите замену `.github/workflows/build.yml`. Не создавайте лишний уровень ScanFlow_Update внутри репозитория.
3. Actions → Build iPhone app → Run workflow. Нужен новый запуск после загрузки исходников. Workflow выбирает Xcode 26+ на macos-26-intel. Наличие свободного runner зависит от GitHub; архив не содержит готовой локально собранной программы.
4. После успешной сборки скачайте артефакт IPA и установите его поверх ScanFlow через SideStore с тем же Apple ID. Не удаляйте приложение со сканами.

## Проверки и ограничения

Локально проверяются синтаксис Swift, состав проекта и отдельная Python-модель алгоритма края. Нативные регрессионные тесты добавлены в tests/main.swift и запускаются workflow. Xcode, iPhone, Vision и интерфейс PhotosPicker здесь не запускались. Сборка и поведение на телефоне ещё требуют проверки в Actions/на устройстве.

Резкость не восстанавливает потерянную при съёмке информацию. Поиск полос ограничен узкой внешней зоной, поэтому намеренная длинная тонкая линия у самого края может оказаться неоднозначной. Для сохранения исходного изображения можно отключить очистку края. Оригиналы не перезаписываются.
